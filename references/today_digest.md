# 今日盤後議題重點(--today digest)

何時讀：執行 `--today`、要整理一份當日全市場議題重點之前。

適用範圍：本檔只規範互動式的 `--today`（使用者當場要議題導向重點）。每天 07:40 的自動盤前信由 `scripts/premarket_digest.ps1` 內嵌的 prompt 產生，不讀本檔，規則也不同（固定區塊、有數量上限、例行月營收不列、不用紅綠圖示），見 [maintenance.md](maintenance.md)。

觸發：使用者說「給我今天的新聞」「今天台股重點」「盤後重點」「今天哪些族群或個股在動」這類沒有指定單一代號或題材、要當日全市場彙整的需求。輸出是給人看的議題導向重點，不是大戶投推播（Sino-notify-skill），也不是完整盤前定稿（sinotrade-morning-briefing）。

## Step 1：取原料（程式做）

```powershell
python -X utf8 "$S\news.py" --today --format=md
```

`--today` 會撈九家即時流（cnyes、udn、ctee、中央社、自由財經、科技新報、ETtoday、MoneyDJ、Yahoo 股市），只留「前一交易日 14:00 到現在」的新聞，去重、依時間倒序、標 sentiment，然後寫兩個檔：

- `out/news_result.json`：`items[].body` 是全文，點名個股時從這裡找內文。
- `out/today_news_YYYYMMDD.md`：表頭統計加依來源分組的清單，每則一行時間、情緒、事件、標題連結，沒有內文。內容和 `--format=md` 的 stdout 相同，stdout 太長被截斷時直接讀這個檔。

07:30 到 08:30 之間不要手動跑 `--today`：自動盤前信正在用這兩個檔。其他時間跑會覆寫當天早上的版本，自動信已寄出就沒有影響。

時間窗為什麼從前一交易日 14:00 起算，而不是今天的日曆日：個股月營收速報多在盤後到傍晚公布，cnyes 把它掛在前一日；只取今天會漏掉整批速報。從前一交易日 14:00 起算，昨晚的營收速報、隔夜美股、今早盤前都會進來。前一交易日會跳過週末與 `data/calendar/tw_holidays.json` 的休市日，連假後第一天回溯到假期前最後一個交易日。

這個窗的限制，整理時要記得：

- 窗只是下界過濾，不保證收齊。每個分類或 feed 只取最新 10 到 15 則（cnyes 五類各 15；udn 八條、Yahoo 四條與其他五家每條 feed 10；ctee 每分類 10），去重後合計約 200 則；高頻來源大約只涵蓋最近十幾小時，窗的前段可能只剩少數來源。
- 沒有發布時間的新聞不會進來。
- `tw_holidays.json` 目前只有 2026 年、尚未對照證交所公告；缺年度或漏列的休市日會讓窗算錯，而且不會有警告。
- 標題固定寫「盤前（涵蓋 MM/DD 14:00～現在）」，盤後執行也一樣；要當日的部分請看 `time` 欄。
- Python 呼叫可以改窗：`news_core.fetch_market_news(since="today")`（只今天）或 `since="days", days=N`（近 N 日），CLI 沒有對應旗標。

## Step 2：整理成「議題導向、有就列出」（模型做）

把時間窗內的全部新聞依議題分組，不是照個股、不是照來源、不是流水帳。每個議題寫成三行：

```text
〔圖示〕<議題標題（事實，不是結論）>
重點：<1 到 2 句，只轉述新聞事實與新聞自己給的因果，含關鍵數字與方向>
受影響個股：<代號 名稱、代號 名稱…>（可分受惠、受害或上下游；純大盤或總經議題可省略）
```

五條鐵律（歷史踩雷整理）：

1. 有就列出，不做門檻篩選。時間窗內有的議題都要列一條。不要用 sentiment 信心分數或「重點候選」之類的門檻去挑，門檻篩選會漏掉低信心但重要的新聞；覆蓋完整性優先於排序，排序只按當日重要性與聲量粗排。寧可長，不可漏。
2. 產業議題不可省略（最常被漏的一類）。面板報價、記憶體報價、運價、MLCC、CCL、銅箔、被動元件景氣、政策法規、法人評等這類「一個議題、一串受影響股、沒有單一主角」的新聞，最容易因為沒有主角股被丟掉，一律各自成題。判準：原料裡有，就一定要有對應議題。
3. 只述事實，不下結論。標題與重點只能轉述新聞講了什麼，加上新聞自己給的因果（例：財測未達預期所以股價跌、運費調漲所以運價彈）。不要加自己的判斷、形容或預測，「沒漲動能」「偏淡」「逆勢」「救火隊」「避風港」「穩住信心」這類都是擅自下結論。查無就說查無，不杜撰。
4. 圖示走台股慣例（紅多綠空）：🔴 利多、🟢 利空、🟡 中性或持平、⚠️ 情緒或估值雜音。議題標題不加編號。
5. 每天逐項掃固定議題類別，確保整類不被忘：大盤與籌碼、隔夜美股與國際、產業報價與趨勢、個股走強、個股走弱與警示、法人評等（Factset 上修下修）、ETF 與制度、重大股東會與法說、政策與公司治理、AI 泡沫與雜音、當期主題（例：COMPUTEX）、上月營收（每月 1 到 10 日是公布高峰，其他日期沒有就省略）。每類都回頭確認今天有沒有，有就列。

大盤與籌碼的數字（指數、成交金額、三大法人、融資券、期貨未平倉）要註明出處與時間，不要從舊新聞抄。週一早上的新聞流常已沒有上週五盤後的籌碼數字。有 Metabase 時可以用 `python -X utf8 "$S\kpi_fetch.py" "$S\..\out\kpi_YYYYMMDD_manual.md"` 取資料庫數字（Metabase 上的 cmoney 表；融資融券是張數乘收盤價估的市值，不是證交所公布的融資金額；引用時出處寫 cmoney 資料庫加資料日。檔名加 `_manual`，不要覆寫自動信當天的 `kpi_YYYYMMDD.md`；exit 0 完整、2 部分、1 失敗，看檔內的資料日是不是今天）。沒有 Metabase 就用新聞裡的數字並標時間，查不到的欄位寫「原料查無」。

## Step 3：點名個股要查證內文

議題的受影響個股要講某檔的催化劑或漲跌原因時，不可只看標題臆測。先從原料找（`out/news_result.json` 約 0.5 MB，不要整檔讀進來，用下面的指令依股名過濾）：

```powershell
python -X utf8 -c "import json,sys; d=json.load(open(sys.argv[1],encoding='utf-8')); k=sys.argv[2]; [print(x['time'][5:16], x['source'], x['title'], '|', x['body'][:300].replace(chr(10),' ')) for x in d['items'] if k in x['title']+x['body']]" "$S\..\out\news_result.json" 雙鴻
```

原料裡沒有、但仍要點名的個股，才補查，每檔最多一次（多檔可合併成 `--keyword=A,B`，預設任一命中），而且一定加 `--out=auto`（不加會覆寫原料）。補查的關鍵字模式回溯至少 10 天，要用 `time` 欄挑出今天的：

```powershell
python -X utf8 "$S\news.py" --keyword=雙鴻 --format=md --out=auto
```

不要每檔都重查；過度補查會把一次整理從幾分鐘拉長到二十分鐘左右（早期個案）。寧可少點名，不要為了湊個股狂補查。查證時：

1. 修正歸類錯誤：用內文驗證族群歸屬（例：貿聯內文是光通訊與 CPO 擴產，歸 CPO，不是液冷）。
2. 釐清專有名詞：照內文寫（例：雙鴻的「IHS」是整合式散熱器，不是浸沒式）。
3. 分清數字出處：董座講的（出貨台數）和法人估的（營收年增率）不要混在一起。
4. 方向以內文為準，查無就說查無；sentiment 標籤只是分群輔助。

## 輸出範本（議題導向 Markdown）

範本裡的單行條目是縮寫，正式輸出每個議題照 Step 2 的三行格式。

```markdown
# 📌 台股今日全議題 ｜ YYYY-MM-DD（盤前、盤中或盤後）
> 🏷 🔴 利多　🟢 利空　🟡 中性　⚠️ 警示或雜音

## 〔大盤·籌碼〕
- 🟢 加權收 X 點（跌 Y 點）、守 X、量 X 兆；三大法人買賣超…、外資…、台指期…（註明數字時間）

## 〔隔夜美股·國際〕
- 🔴 或 🟢 道瓊… 費半… 日韓… 油金…

## 〔產業報價·趨勢〕   ← 面板、記憶體、運價、被動元件、CCL、散熱… 有就各自成題，不可省
- 🟡 集邦估當月面板：電視與筆電持平、監視器部分漲 → 友達(2409)、群創(3481)、彩晶(6116)
- 🔴 SCFI 連 6 彈 +6% → 長榮(2603)、陽明(2609)、慧洋(2637)…

## 〔個股·走強〕／〔個股·走弱警示〕
- 🔴 <個股(代號)>：<事實：創高、漲停、接單…（已查證內文）>

## 〔法人評等（Factset）〕
- 🔴 上修：<股（EPS、目標價）>… ｜ 🟢 下修：<股>…

## 〔ETF·制度〕〔重大股東會·法說〕〔政策·公司治理〕〔AI 泡沫·雜音〕〔當期主題〕
- 逐項：有就列（同上格式）

## 📊 上月營收（逐檔全列、依 YoY 排序，不砍；公布期以外沒有就省略）
| 代號 名稱 | 月營收 | YoY |  ← 🔸 標低基期

> 完整含連結清單在 out/today_news_YYYYMMDD.md。
```

一句話：`--today` 取前一交易日 14:00 到現在的新聞，依議題分組、有就列出（不設門檻、產業議題不可省），只述事實不下結論、紅多綠空，點名個股先查原料內文、不夠才補查一次，營收逐檔全列。
